# FunPay Medik

**FunPay Medik** — Telegram-помощник для автоматизации рутинных процессов продавца FunPay. Проект: [@Funpay_medik](https://t.me/Funpay_medik).

Python, aiogram 3, SQLite и библиотека [LIMBODS/FunPayAPI](https://github.com/LIMBODS/FunPayAPI).

> ⚠️ Это ранняя рабочая основа, а не полностью завершённый автопродавец. Интерфейс, команды, база и проверка/шифрование golden_key реализованы. Рыночный парсер, история продаж, отложенные сообщения покупателям, создание лотов и изменение цен требуют отдельных проверенных интеграций с актуальным API FunPay. Эти действия не имитируются.

## Что уже есть

- /start с описанием команд и постоянной нижней клавиатурой.
- /help с подсказками; команды зарегистрированы в меню Telegram.
- Кнопки: 📊 Профиль, 💸 Товары, 📈 Статистика, ⚡ Уведомления.
- /auth и /login — проверка golden_key через FunPayAPI.Account(...).get().
- Сессия шифруется Fernet перед сохранением в SQLite.
- /profile — профиль и доступный баланс; неизвестные поля не выдумываются.
- /products — запрос лотов через get_sells, если метод доступен в установленной версии.
- /notifications — сохранение переключателей.
- /auto-price — сценарий выбора категории; мониторинг не стартует без достоверного источника цен.
- /auto-otvet — переключатель будущих напоминаний; отправка пока не активирована.
- /auto-expose — подготовка к созданию лота; публикация пока отключена.
- /cancel — отмена сценария.

## Установка

Требуется Python 3.11+.

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/eerdertyu/Funpay-mediknew-auto-seller.git
   cd Funpay-mediknew-auto-seller
   ```
2. Установите зависимости:
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   # Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Создайте .env на основе .env.example.
4. Получите BOT_TOKEN у @BotFather.
5. Сгенерируйте ключ шифрования:
   ```bash
   python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
   ```
   Вставьте его в AUTH_ENCRYPTION_KEY. Сохраните отдельно: без него сессии восстановить нельзя.
6. Запустите: `python main.py`.

## Переменные окружения

| Переменная | Назначение |
|---|---|
| BOT_TOKEN | Токен Telegram |
| AUTH_ENCRYPTION_KEY | Ключ Fernet для шифрования сессий |
| DATABASE_PATH | Путь к SQLite, по умолчанию data/funpay_medik.sqlite3 |
| FUNPAY_POLLING_DELAY | Интервал событий FunPay (зарезервирован) |
| PROJECT_TELEGRAM | Контакт проекта |

## Безопасность

- Не добавляйте .env, Telegram token или golden_key в Git.
- Авторизуйтесь только в личном чате с ботом.
- Бот удаляет сообщение с ключом после обработки, если Telegram разрешает.
- Golden_key хранится в базе только зашифрованным.
- Не храните базу и ключ шифрования в одном публичном месте.
- Финансовые операции, изменение цен и публикация должны требовать подтверждения владельца.
- Проверьте правила FunPay и условия сторонней библиотеки.

## План разработки

1. Проверенная интеграция с каталогом категорий и подкатегорий FunPay.
2. Средняя/минимальная/максимальная цена и число продавцов с обновлением раз в 15 минут.
3. Сравнение собственных лотов с конкурентами, лимиты цены и подтверждение.
4. История заказов, дохода, отзывов и графики статистики.
5. Обработчик событий заказов и одноразовые напоминания через час.
6. Создание и редактирование лотов, варианты описаний и перевод с подтверждением публикации.
