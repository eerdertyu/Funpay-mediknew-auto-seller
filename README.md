# FunPay Medik — Auto Seller

Основа проекта для бота автоматической выдачи товаров на FunPay.

## Возможности в плане разработки

- Отслеживание новых заказов.
- Автоматическая выдача цифрового товара после подтверждения заказа.
- Логирование событий и ошибок.
- Конфигурация через переменные окружения.
- Защищённое хранение токенов и сессионных данных.

## Запуск

1. Установите Python 3.10 или новее.
2. Создайте виртуальное окружение: `python -m venv .venv`.
3. Установите зависимости: `pip install -r requirements.txt`.
4. Скопируйте `.env.example` в `.env` и заполните настройки.
5. Запустите: `python bot.py`.

> Проект пока является стартовым каркасом. Перед подключением к реальному аккаунту проверьте актуальную документацию используемой версии FunPayAPI. Не публикуйте файл `.env`, cookies или golden_key.

## Безопасность

- Не храните секреты в исходном коде.
- Не отправляйте товар, пока заказ не проверен.
- Финансовые действия и возвраты не автоматизируются без отдельного явного подтверждения.
